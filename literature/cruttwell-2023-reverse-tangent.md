# Reverse Tangent Categories

[arXiv abstract](https://arxiv.org/abs/2308.01131) · [PDF](https://arxiv.org/pdf/2308.01131)

## General summary

## Relevancy to the research
Provides the overarching type of base category in deep learning contexts where the data is non-Euclidean. The category of manifolds with smooth maps is not a reverse derivative category, and so we must generalize to categories of manifolds, which are reverse tangent categories. This is related to generalized backpropagation abstractions.
