# Priors change the function space
Taken from 

> In machine learning we assume that the labels $y$ are generated by an unknown function $f$, such that $y_i = f(x_i)$. The learning problem or "task" reduces to estimating the function $f$ using a parametrized function class $\mathcal F = \{f_{θ∈Θ}\}$. Neural networks are a common realization of such parametric function classes, in which case $θ ∈ Θ$ corresponds to the network weights. (Section 2.0)
> 
> A successful learning scheme needs to encode the appropriate notion of regularity or *inductive bias* for $f$, imposed through the construction of the function class $\mathcal{F}$ and the use of regularization. (Section 2.0)

So the authors imposes priors, which means they impose a certain mathematical structure or condition such that one can build a function class from those structures that satisfy the conditions.
