# Literature workflow

In Obsidian, run your Add paper to research project template from a personal
paper note. Choose the program's literature folder, topic, optional subtopic,
and project relevance score. The project note contains bibliographic metadata
and an empty relevance section. Summaries, personal notes, PDFs, and personal
vault links are not copied.

Commit and push your project notes as usual. GitHub generates the literature
README by topic and subtopic. The marked index section is generated; surrounding
handwritten text is retained. There is no local build step or dependency install.

The metadata properties are `title`, `authors`, `year`, `citekey`, `topic`,
`subtopic`, `relevance`, and available external identifiers and links.
