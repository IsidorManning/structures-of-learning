Another possible construction is:
$$\text{Impl}_{\mathcal{C}}:\mathbf{Prior}^{\text{op}}\times \mathbf{Arch}_{\mathcal{C}}\to{}\mathbf{Cat}$$
where $\mathbf{Arch}_{\mathcal{C}}$ is a category of architecture presentations, for instance, $\mathbf{Set}$, or $\mathbf{Para}_{}(\mathbf{Set})$. Then, we might construct a functor which yields a category of ways in which an architecture presentation $A$ realizes a prior $P$. But this seems to depend on whether architectural syntax (or "wiring topology") determines whether an implemented model respects a prior. This might not be the case generally. 

This directly recognizes the problem in [[../../../literature/nye-2025-categorical-construction|nye-2025-categorical-construction]] which is elaborated on in [[../questions/prior-architecture-relations|prior-architecture-relations]]: a Lawvere theory does not canonically select real carrier spaces, differentiable realizations, parameter spaces, or neural implementations.
