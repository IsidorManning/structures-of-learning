## Question
Can it be useful to think of relations between priors? For example, the relation between an invariance prior and an equivariance prior. Loosely speaking, how does that relation between priors translate to a relation between architectures, if there even is such structure empirically?

## Answers log

- **2026-10-16:** It certainly can be interesting to think about morphisms between priors. For example, there exists a morphism from geometric priors, described using a one-object category whose morphisms are isomorphisms, to priors whose specification is that of a groupoid. Moreover, we can go the other way, and define a morphism from a groupoid prior to a group prior if the groupoid is connected, in which case we can consider its isotropy group. I am convinced there exists a theoretical induced relation when considering morphisms between parameterized maps and prior morphisms. The question whether there exist an empirically valid interpretation of such relation is yet to be shown experimentally.
- **2026-11-02:** I will focus on the question whether a prior morphism (however we develop/abstract it) transport to a useful morphism of architectures in [[prior-to-arch-morphism]].
